# E-Commerce Sales Analysis — SQL

## Project Overview

Designed and implemented a relational e-commerce database using MySQL with 6 interconnected tables for analyzing customers, products, orders, payments, and sales.

## Database Tables

- Customers
- Products
- Categories
- Orders
- Order_Details
- Payments

## SQL Concepts Used

- SELECT and WHERE
- SQL Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- CTEs
- Window Functions
- RANK()
- Primary Keys and Foreign Keys

## Analysis Performed

- Customer and order analysis
- Top-selling products
- Category-wise sales
- Monthly sales analysis
- Repeat customer analysis
- Highest revenue-generating products
- Sales ranking using RANK() Window Function

## Tools

- MySQL
- MySQL Workbench

## Project Files

`ecommerce_project_queries.sql` contains the SQL queries performed for the analysis.
